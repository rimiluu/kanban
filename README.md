# わたしの読書記録

## 使う人と用途

使う人：読みたい本が増えて、どの本を読み始めたか・読み終えたかを整理したい自分。

用途：気になる本を登録し、「読みたい・読んでいる・読了」の3段階で読書の進み具合を記録する。

## 画面のアレンジ

- タイトル：📚 わたしの読書記録
- 左の列：読みたい（薄紫）
- 中央の列：読んでいる（薄い黄色）
- 右の列：読了（薄い青緑）
- 入力欄：本のタイトル
- 入力例：吾輩は猫である
- 追加ボタン：読みたい本に追加
- 件数の単位：冊

## 操作確認に使う本の例

1. 吾輩は猫である → 読みたい
2. 銀河鉄道の夜 → 読んでいる
3. 走れメロス → 読了

アプリで3冊を追加し、左右のボタンで上記の列へ移動する。
タイトルの編集、キャンセル、削除を確認する。
ページを再読み込みし、本のタイトルと状態が復元されることを確認する。
上記は確認用の例で、初期データとして自動登録はしない。
